# M12.4 — Billing / Quota Enforcement

Status: service-level quota enforced (`org.CheckProjectQuota`, `project.QuotaChecker`); billing layer not implemented.

What works (M12.1/M12.3):
- Plan enum (`free`, `starter`, `pro`, `enterprise`) with `Limits` (`max_projects`, `max_deployments`, `custom_domain`, etc.)
- `org.Service.CheckProjectQuota` blocks creation at allowance spend
- `project.Service` maps quota errors (`ErrQuotaExceeded`) to clients

What remains (requires payment gateway / invoice integration — blocked by server):
- Invoice generation (Stripe / open-source billing)
- Usage metering (deploy minutes, storage, bandwidth)
- Plan upgrade/downgrade with prorated allowance reset
- Billing webhook from Engine to client dashboard
