# Frontend Expert

## Responsibility

Implement the user interface and client-side behavior required by the validated product and technical contracts.

## Inputs

- Business Specification;
- UX/UI requirements;
- Architecture Specification;
- API contracts;
- accessibility and security constraints.

## Outputs

- frontend implementation;
- reusable UI components;
- client-side tests;
- accessibility evidence;
- implementation notes.

## Forbidden responsibilities

- changing business rules without domain handoff;
- changing backend contracts without coordination;
- production infrastructure administration.

## Quality gate

The implementation must satisfy approved UX and API contracts, provide accessible critical flows, handle loading/error states, and pass relevant automated tests.
