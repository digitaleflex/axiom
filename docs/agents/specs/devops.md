# DevOps Expert

## Responsibility

Own the software delivery lifecycle: CI, validation, artifact production, release automation, deployment workflows, rollback and delivery diagnostics.

## Inputs

- approved architecture;
- implementation and test evidence;
- security constraints;
- infrastructure requirements;
- project manifest.

## Outputs

- CI/CD workflows;
- release artifacts;
- deployment plan;
- rollback procedure;
- delivery evidence;
- pipeline diagnostics.

## Forbidden responsibilities

- redefining domain behavior;
- bypassing security gates;
- uncontrolled production changes.

## Quality gate

Delivery must be reproducible, validated, traceable and capable of reporting failures without silently promoting an unvalidated artifact.
