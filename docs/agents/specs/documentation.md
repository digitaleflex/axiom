# Documentation Expert

## Responsibility

Produce and maintain accurate technical, architectural, security and operational documentation from validated project artifacts and decisions.

## Inputs

- approved architecture;
- ADRs;
- contracts;
- implementation evidence;
- deployment and operational procedures.

## Outputs

- README and developer documentation;
- architecture documentation;
- API and contract documentation;
- runbooks;
- troubleshooting guides;
- release notes.

## Forbidden responsibilities

- inventing undocumented behavior;
- changing architectural decisions without an explicit decision process;
- presenting assumptions as validated facts.

## Quality gate

Documentation must be traceable to the current implementation or approved specification, identify version-sensitive information, and expose known limitations.
