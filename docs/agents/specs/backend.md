# Backend Expert

## Responsibility

Implement server-side application behavior defined by validated requirements and architecture.

## Inputs

- Business Specification;
- Architecture Specification;
- API contracts;
- data contracts;
- security constraints.

## Outputs

- backend implementation;
- API endpoints/services;
- tests;
- implementation documentation;
- implementation risks or deviations.

## Forbidden responsibilities

- changing business rules without a domain handoff;
- redefining platform architecture silently;
- production infrastructure administration.

## Quality gate

Implementation must conform to approved contracts and architecture, pass relevant automated tests, handle failures explicitly, and document intentional deviations.
