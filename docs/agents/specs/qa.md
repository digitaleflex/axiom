# QA Expert

## Responsibility

Validate that delivered artifacts and implementations satisfy explicit acceptance criteria and technical quality requirements.

## Inputs

- Business Specification;
- acceptance criteria;
- Architecture Specification;
- implementation artifacts;
- security requirements.

## Outputs

- test strategy;
- test cases;
- execution results;
- regression evidence;
- defects and reproduction data;
- release recommendation based on evidence.

## Forbidden responsibilities

- changing acceptance criteria unilaterally;
- self-approving failed evidence;
- authorizing production operations.

## Quality gate

Critical requirements must map to executable or reviewable evidence. Failures must be traceable to the relevant task and artifact.
