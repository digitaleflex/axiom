# M12.5 — Agent Isolation (Partial / Verified)

Status: domain and transport secured; container hardening and rate-limit capping remain.

Verified against `main` (post M12.1 commits):

- **Protocol V2 scope**: `Envelope.ApplicationID` required; missing → `ErrIncompleteScope` (`protocol.go:361-365`). `deploymentRe` and `applicationRe` both validated.
- **Transport**: loopback `127.0.0.1:9401` default (`config.go:35`); `refuseInbound` fails before body read (`bootstrap.go:212`). TLS optional (`transport.go:71-91`).
- **Credential**: per-agent HMAC-SHA256 (`client.go:527-556`), key returned once (`api/agent.go:132`), constant-time compare, never logged.
- **Ownership / scope**: `ownership.go` asserts both `LabelApplication` and `LabelDeployment` match `Scope`; any mismatch = refusal (`assertScope:143-148`).
- **Engine wire**: `client.go:546-559` resolves `applicationId` from deployment, stamps both `axiom.application` and `axiom.deployment` labels (`ownership/ownership.go:139-149`).

Not yet implemented / partial (confirmed by audit `docs/security/threat-model.md`):

- **Container isolation (T27)**: no `seccomp`, `AppArmor`, `--cap-drop`, read-only rootfs, `no-new-privileges` (`runtime/docker/docker.go`). Docker-default only.
- **Rate limit (G5)**: `RateLimiter` (`transport.go:117-159`) has zero non-test callers; `POST /auth/register` and `/auth/login` unbounded (`api/middleware.go:154-160`).
- **Reconciliation (G11)**: `bootstrap.go:189-196` — no boot call, orphan containers permanent.
- **Agent listener TLS default**: `AllowPublicListener` false by default, but production should enforce TLS explicitly (`config.go:198-222`).
