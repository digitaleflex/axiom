# Axiom Scope

## Platform responsibilities

- Technical architecture and contracts
- Expert-agent framework
- Orchestration
- Runtime operations
- Infrastructure integration
- Security and governance
- Observability
- Developer experience

## Domain-project responsibilities

- Business requirements
- Domain rules
- Product workflows
- Project-specific user experience
- Domain data semantics

## Boundary rule

Axiom must remain usable when the domain project is replaced by another project with different business requirements.
