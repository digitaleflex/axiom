# Axiom V0.1 Scope

## Objective
Axiom V0.1 proves the core product promise: connect GitHub, analyze an application, generate a deployment plan, deploy it to an eligible server, verify health and make it LIVE.

## V0.1 acceptance journey
Authenticate → Connect GitHub → List repositories → Select repository/ref → Analyze → Application Profile → Select eligible server → Generate Deployment Plan → Review → Create deployment → Observe realtime progress → Build → Deploy → Health verification → LIVE → Return live URL → Inspect logs/events

## In scope
### Product
- Cloud Console foundation
- GitHub connection and repository discovery
- Repository analysis
- Canonical Application Profile
- Server selection
- Deployment Plan
- Deployment execution
- Deployment state machine
- Deployment logs/events
- Health verification
- Domain/TLS integration boundary
- Basic application/server operational views

### Engine
- Go Engine foundation
- PostgreSQL persistence
- REST API /api/v1
- SSE deployment events
- Deployment Planner
- Build Engine
- Deployment Executor
- Idempotency boundary
- Security and authorization foundations

### Runtime Agent
- Agent registration
- Authentication
- Heartbeat/liveness
- Capability/resource discovery
- Authorized operation dispatcher
- Docker runtime adapter
- Traefik network adapter
- Health/readiness
- Bounded logs/metrics
- Ownership/security boundaries
- Recovery/reconciliation foundations

## Explicit V0.1 runtime model
Axiom Engine → Runtime Agent → Docker → Traefik → Application Runtime

MicroVMs, service-mesh infrastructure and other advanced isolation/networking technologies are future architecture options unless separately specified by a versioned contract.

## Out of scope for V0.1
- Kubernetes-first deployment
- Multi-cloud orchestration
- Advanced autonomous infrastructure optimization
- Agent marketplace
- Full commercial billing implementation
- Multi-region orchestration
- Arbitrary remote shell
- Fully autonomous destructive operations
- GitLab and additional source-control providers
- Advanced backup orchestration

## V0.1 success criteria
A conforming implementation can execute the documented GitHub → LIVE workflow using only Axiom Engine contracts. The Cloud Console never communicates directly with Docker, Traefik, PostgreSQL, Runtime Agents or deployment servers. A deployment becomes LIVE only after successful health verification.
