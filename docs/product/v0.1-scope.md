# Axiom v0.1 Scope

## In scope

- Canonical architecture and terminology
- Platform/domain separation
- Agent contracts and capabilities
- Artifact and handoff contracts
- Orchestration foundation
- Runtime agent foundation
- Reusable project template
- Security baseline
- Observability baseline
- CLI foundation
- One reference project

## Out of scope for v0.1

- Kubernetes-first deployment
- Billing platform
- Agent marketplace
- Advanced autonomous infrastructure optimization
- Multi-region orchestration
- Fully autonomous destructive operations

## Success criteria

A developer can understand the architecture, initialize a project from the reusable foundation, execute the defined expert workflow and reproduce a deployed reference project using documented procedures.
