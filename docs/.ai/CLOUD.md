# Frontend Client

Le frontend Cloud représente l'expérience utilisateur finale côté client.

## Objectifs
- Fournir une interface fluide pour les usages métiers.
- Rester thin côté logique, avec l'Engine comme source de vérité.
- Favoriser la cohérence avec Core lorsque des composants sont partagés.

## Recommandations
- Limiter la logique applicative au niveau des services dédiés.
- Maintenir des composants simples et testables.
- Respecter les principes d'accessibilité et d'expérience utilisateur.
