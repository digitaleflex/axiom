# Workflow Git

Le dépôt Git doit être utilisé de manière claire et prévisible.

## Recommandations
- Travailler sur des branches dédiées par sujet.
- Faire des commits courts et explicites.
- Vérifier l'état du dépôt avant de publier des changements.
- Éviter les modifications non liées dans un même commit.

## Bonnes pratiques
- Réviser les changements avant de les fusionner.
- Maintenir un historique lisible et compréhensible.
- Documenter les changements importants lorsqu'ils affectent l'architecture.
