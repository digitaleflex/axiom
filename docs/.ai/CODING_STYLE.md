# Style de codage

## Go
- Favoriser la clarté et la simplicité.
- Utiliser des fonctions courtes et explicites.
- Éviter les abstractions inutiles.
- Préférer les erreurs explicites et les logs structurés.

## TypeScript
- Écrire un code lisible et cohérent.
- Garder les composants modulaires.
- Favoriser la composition plutôt que l'héritage.
- Utiliser des types de manière explicite.
