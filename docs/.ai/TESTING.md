# Stratégie de tests

Les tests doivent accompagner le développement pour garantir la stabilité du système.

## Priorités
- Préférer les tests unitaires et d'intégration.
- Couvrir les portions critiques de l'infrastructure.
- Vérifier les comportements clés avant déploiement.

## Recommandations
- Écrire des tests adaptés aux cas d'usage réels.
- Éviter les tests trop dépendants de mocks.
- Maintenir des suites de tests cohérentes et fiables.
