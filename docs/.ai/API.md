# Conventions REST

Les APIs doivent être conçues de manière cohérente et standardisée.

## Standards
- Utiliser REST comme modèle principal.
- Respecter les méthodes HTTP standard : GET, POST, PUT, PATCH, DELETE.
- Retourner des réponses JSON structurées.
- Utiliser les codes HTTP appropriés.

## Recommandations
- Valider systématiquement les entrées.
- Documenter les endpoints et leurs comportements.
- Maintenir une séparation claire entre API et logique métier.
