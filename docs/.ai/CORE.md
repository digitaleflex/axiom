# Frontend Admin

Le frontend Core correspond à l'interface d'administration et de gestion du système.

## Objectifs
- Offrir une expérience d'administration claire et robuste.
- Centraliser les vues de supervision et de configuration.
- Réutiliser les composants communs avec Cloud quand c'est pertinent.

## Recommandations
- Garder la logique métier côté Engine.
- Maintenir une interface simple et cohérente.
- Privilégier les composants réutilisables.
