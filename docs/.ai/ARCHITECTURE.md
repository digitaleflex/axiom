# Résumé de l'architecture

Le projet Axiom est organisé autour d'une architecture modulaire et orientée plateforme.

## Composants principaux
- Engine : source de vérité et cœur du système.
- Agent : orchestration locale et opérations.
- Core : frontend d'administration.
- Cloud : frontend client.

## Principes retenus
- API first.
- Documentation first.
- Security by design.
- Self-hosted first.
- Architecture extensible par plugins.
