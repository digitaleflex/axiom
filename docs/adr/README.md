# Architecture Decision Records

Architecture Decision Records (ADRs) document significant technical and architectural decisions in Axiom.

## Rules

Each ADR must contain:

- context;
- decision;
- consequences;
- alternatives considered when relevant;
- status;
- date.

Superseded decisions remain in the repository and must link to the decision that replaces them.

## Initial ADR set

- ADR-0001 — Platform/domain separation
- ADR-0002 — Go for core technical services
- ADR-0003 — PostgreSQL as primary relational database
- ADR-0004 — Docker Compose before Kubernetes
- ADR-0005 — Traefik as initial edge/reverse-proxy layer
- ADR-0006 — OpenTelemetry-based observability
- ADR-0007 — Explicit contracts between experts and orchestrator

These ADRs establish the initial direction and remain subject to revision through the normal architecture process.
