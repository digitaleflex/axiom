# Axiom Design Master Prompts

This directory contains the canonical prompts used to produce Axiom's UI/UX design deliverables one stage at a time.

## Workflow

1. Product UI Brief
2. UX & Information Architecture
3. Design DNA
4. Google Stitch Exploration
5. Screen System
6. Design Validation
7. Figma / Design Handoff
8. Frontend Agent Implementation
9. Visual QA
10. Final Design System

## Operating rule

Process these prompts sequentially.

After each prompt:

1. Save the generated result in the repository.
2. Review the result.
3. Do not silently change the source requirements.
4. Use the result as input to the next stage.
5. If a stage reveals an architectural or product ambiguity, record it before continuing.

## Result convention

Each stage should produce a versioned artifact:

`01-product-ui-brief.md`
`02-ux-information-architecture.md`
`03-design-dna.md`
`04-stitch-exploration.md`
`05-screen-system.md`
`06-design-validation.md`
`07-design-handoff.md`
`08-frontend-implementation.md`
`09-visual-qa.md`
`10-final-design-system.md`

The prompts themselves are stored below and should remain stable unless the design process is intentionally revised.
