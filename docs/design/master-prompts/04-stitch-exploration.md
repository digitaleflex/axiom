# Master Prompt 04 — Google Stitch Exploration

Use the approved Axiom Product UI Brief, UX Architecture and Design DNA as the source context.

You are designing a premium developer-first cloud deployment platform called **AXIOM**.

Axiom transforms a GitHub repository into a deployed application.

Core experience:

GitHub → Analyze → Configure → Deploy → Observe → LIVE.

Create a distinctive desktop-first SaaS/cloud console.

The visual language must feel:

premium, technical, precise, calm, powerful, modern, infrastructure-grade.

The interface is for serious developers and technical teams.

Avoid generic SaaS dashboard patterns.

Do not imitate Vercel, Linear, Railway, Render, AWS or another existing product.

Create a visual identity capable of scaling across:

- dashboard
- repositories
- GitHub integration
- application analysis
- deployment configuration
- deployment plan
- live deployment
- logs
- metrics
- servers
- domains
- settings

Prioritize:

- information hierarchy
- excellent typography
- high-quality spacing
- subtle depth
- clear status communication
- deployment progress visualization
- developer confidence

Explore multiple coherent visual directions while preserving the product requirements.

For each direction explain:

- visual concept
- strengths
- risks
- scalability
- recommended use

Do not average unrelated directions together.

The output must be suitable for selecting one canonical Axiom art direction before implementation.
