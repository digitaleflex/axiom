# Master Prompt 07 — Axiom Figma / Design Handoff

Convert the approved Axiom interface into a production-ready design specification.

For every component define:

- name
- purpose
- anatomy
- dimensions
- spacing
- typography
- colors
- states
- variants
- interaction
- accessibility
- responsive behavior

For every screen define:

- layout
- grid
- regions
- components
- required data
- states
- interactions
- responsive rules

Create:

1. Component inventory
2. Token inventory
3. Screen inventory
4. Interaction specifications
5. Accessibility requirements
6. Developer handoff notes

The result must allow a frontend engineer to implement the interface without guessing visual or interaction decisions.

Reference the approved design direction and preserve it.
