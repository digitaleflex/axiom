# Master Prompt 06 — Axiom Design Validation

Act as a Principal Product Designer reviewing the current Axiom interface.

Do not redesign it immediately.

Perform a rigorous design audit.

Evaluate:

1. Visual hierarchy
2. Navigation clarity
3. Information density
4. Typography
5. Spacing
6. Alignment
7. Component consistency
8. Status communication
9. Deployment comprehension
10. Error handling
11. Loading states
12. Empty states
13. Accessibility
14. Developer experience
15. Cognitive load
16. Visual distinction
17. Brand consistency
18. Scalability
19. Responsive behavior
20. Production readiness

Classify every issue:

CRITICAL
HIGH
MEDIUM
LOW

For each issue provide:

- Problem
- Why it matters
- Recommended correction
- Expected UX impact

Do not introduce a new visual direction unless necessary.

The objective is to improve the approved Axiom direction while preserving its identity.

## Deliverable

Produce a structured design audit and a prioritized correction plan.
