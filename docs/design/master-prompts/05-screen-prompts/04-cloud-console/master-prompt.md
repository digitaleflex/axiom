# Master Prompt — Axiom Cloud Console Screen System

Act as a Principal Product Designer and UI Art Director for Axiom.

## Objective

Generate the **actual high-fidelity visual screens** for the Cloud Console surface of Axiom.

This is a visual-generation prompt. **Do not return an architecture document, UX essay, textual screen specification, wireframe description, or component inventory. The visible UI mockups are the primary deliverable.**

## Source of truth

Use, in this order:
1. Axiom Product UI Brief
2. Axiom UX & Information Architecture
3. Axiom Design DNA
4. Approved Axiom visual direction
5. Axiom API/architecture contracts where operational data is relevant

## Scope

Dashboard; GitHub Connection; Repository List; Repository Detail; Repository Analysis; Application Profile; Server Selection; Deployment Configuration; Deployment Plan; Deployment Progress; Deployment Success; Deployment Failure. This is the core GitHub → LIVE product journey.

## Visual rules

- Preserve the approved Axiom visual language across every screen.
- Use realistic synthetic data.
- Keep developer/DevOps-grade information density where appropriate.
- Use the established semantic status system consistently.
- Preserve environment context where relevant.
- Use monospace for technical identifiers, commands, SHAs, logs and timestamps where appropriate.
- Design desktop-first but include responsive behavior.
- Avoid generic SaaS filler.
- Do not imitate another company's interface.

## Output requirement

Generate the screens visually. Each requested screen should exist as a coherent UI frame/artifact with its own state and primary action.

**Do not replace visual output with prose.**
