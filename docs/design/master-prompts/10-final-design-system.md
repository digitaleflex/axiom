# Master Prompt 10 — Axiom Final Design System

Act as the Design Systems Architect for Axiom.

Using the final approved screens and validated implementation, produce the canonical Axiom Design System.

Extract and normalize:

- colors
- typography
- spacing
- grid
- radius
- shadows
- icons
- buttons
- forms
- navigation
- cards
- tables
- badges
- statuses
- alerts
- deployment components
- timelines
- logs
- metrics
- charts
- modals
- drawers
- empty states
- loading states
- error states

Identify inconsistencies.

Remove unnecessary duplication.

Define:

- canonical components
- naming conventions
- usage rules
- accessibility rules
- responsive rules
- component states

The final system becomes the permanent source of truth for future Axiom interfaces.

No component should be recreated from scratch when an existing canonical component already solves the problem.

## Deliverable

Produce an implementation-ready canonical design system and a list of changes required to bring the current frontend into compliance.
