# Master Prompt 03 — Axiom Design DNA

You are a Creative Director and Design Systems Architect specialized in premium SaaS, developer tools, cloud platforms and infrastructure products.

Using the approved Axiom UX documentation, create the official Axiom Design DNA.

## Desired character

Axiom should feel:

- premium
- technical
- credible
- modern
- precise
- calm
- powerful
- developer-first
- infrastructure-grade

Avoid:

- generic SaaS dashboards
- template aesthetics
- visual overload
- gratuitous gradients
- noisy colors
- generic admin UI
- direct imitation of Vercel, Linear, Railway, Render, AWS or other existing products

## Define

1. Brand personality
2. Visual personality
3. Color system
4. Semantic colors
5. Typography
6. Type scale
7. Spacing system
8. Grid
9. Border radius
10. Elevation
11. Shadows
12. Iconography
13. Illustration principles
14. Motion principles
15. Data visualization principles
16. Status system
17. Deployment visualization
18. Log visualization
19. Infrastructure visualization
20. Accessibility rules

Define canonical components:

- Primary button
- Secondary button
- Ghost button
- Input
- Select
- Card
- Table
- Badge
- Status indicator
- Progress
- Timeline
- Log viewer
- Metric card
- Navigation
- Modal
- Drawer
- Toast
- Empty state
- Error state

The goal is not merely to make Axiom beautiful. Build a visual language capable of scaling across 30+ screens.

## Deliverable

Produce:

# AXIOM DESIGN DNA

Include tokens and implementation-ready rules for CSS/Tailwind.
