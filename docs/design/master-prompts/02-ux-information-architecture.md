# Master Prompt 02 — UX & Information Architecture

Using the approved Axiom Product UI Brief, act as a Principal UX Designer specialized in technical SaaS.

## Objective

Design the complete Information Architecture and User Flows for Axiom.

Do not define visual style yet.

Define:

1. Global application architecture
2. Navigation model
3. Sidebar structure
4. Header structure
5. Dashboard hierarchy
6. Application hierarchy
7. Deployment hierarchy
8. Server hierarchy
9. GitHub hierarchy
10. Domain hierarchy
11. Settings hierarchy

## Required flows

FLOW 01 — Sign in → Dashboard
FLOW 02 — Connect GitHub
FLOW 03 — Select repository
FLOW 04 — Analyze repository
FLOW 05 — Review application profile
FLOW 06 — Select server
FLOW 07 — Configure deployment
FLOW 08 — Review deployment plan
FLOW 09 — Start deployment
FLOW 10 — Monitor deployment
FLOW 11 — Application becomes LIVE
FLOW 12 — Inspect logs
FLOW 13 — Inspect health
FLOW 14 — Manage domain
FLOW 15 — Inspect server

For every flow define:

- Entry point
- User intent
- Screen
- Action
- System response
- Next state
- Failure state
- Recovery path

Define all relevant states:

Loading, Empty, Success, Error, Warning, Pending, Processing, Live, Failed, Cancelled, Offline, Degraded.

## Deliverable

Produce documents directly usable by UI designers, Figma designers and frontend engineers.

Do not define colors, typography or visual styling.
