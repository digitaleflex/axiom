# Master Prompt 05 — Axiom Screen System

Using the approved Axiom visual direction as the immutable reference, generate the complete application screen family.

Do not redesign the visual language between screens.

Maintain:

- typography
- spacing
- components
- navigation
- status system
- interaction patterns
- visual hierarchy

Create:

01 Dashboard
02 GitHub Connection
03 Repository List
04 Repository Detail
05 Repository Analysis
06 Application Profile
07 Server Selection
08 Deployment Configuration
09 Deployment Plan
10 Deployment Progress
11 Deployment Success
12 Deployment Failure
13 Application Overview
14 Application Deployments
15 Application Logs
16 Application Metrics
17 Application Domains
18 Server Overview
19 Server Details
20 Settings

For every screen include, where applicable:

- default state
- loading state
- empty state
- error state
- success state
- permission state

The result must feel like one coherent product, not twenty unrelated designs.

Document the purpose and primary user action of every screen.
