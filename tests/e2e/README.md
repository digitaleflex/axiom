# End-to-End Tests

E2E tests will validate the complete Axiom workflow using a real reference project.

Target flow:

```text
Project specification
→ Business Expert
→ Architecture
→ Implementation
→ Security
→ QA
→ DevOps / Infrastructure
→ Runtime Agent
→ deployed application
```

Acceptance must include traceability of tasks and artifacts, quality gates, authorization boundaries, deployment outcome, health checks and recovery behavior where applicable.
